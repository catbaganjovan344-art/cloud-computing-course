# Cloud Computing Concepts Reflection

Cloud computing has become an important part of my daily life, even before I started studying it in class. Many of the applications I use rely on cloud technology to store data, provide services, and allow access from different devices. Understanding these concepts helps me appreciate how modern technology works behind the scenes.

One cloud service I use regularly is **Google Drive**. It is an example of **Software as a Service (SaaS)** because I can store, edit, and share files through a web browser without installing or managing the underlying infrastructure. It is commonly deployed using the **Public Cloud** model since the service is available to millions of users over the internet.

Another service I frequently use is **Facebook Messenger**. Messenger is also classified as **SaaS** because users simply access the messaging application while Meta manages the servers, software, and maintenance. It operates through a **Public Cloud** deployment model because it serves a large global user base through shared cloud infrastructure.

I also use **Canva** for creating presentations, posters, and other designs. Canva is another example of **SaaS** because it provides ready-to-use design tools through a web browser. Like the previous examples, it is primarily delivered through the **Public Cloud**, making it accessible from anywhere with an internet connection.

Version control is essential when working on cloud infrastructure because changes to configurations or application code can directly affect running systems. Git and GitHub provide a reliable way to record every modification, making it easier to review updates, restore previous versions, and identify mistakes. GitHub also allows multiple team members to work on the same project simultaneously using branches, pull requests, and code reviews. These features reduce conflicts, improve collaboration, and ensure that cloud resources are managed in an organized and secure manner. Learning GitHub alongside cloud computing prepares me for real-world projects where teamwork, documentation, and careful change management are critical to successful cloud deployments.
