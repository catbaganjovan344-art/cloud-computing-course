# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers a wide range of cloud services for computing, storage, networking, databases, security, artificial intelligence, and application development. Organizations can use AWS to build, deploy, and manage applications without having to maintain all of their own physical infrastructure.

## Global Infrastructure

AWS operates a large global infrastructure consisting of Regions, Availability Zones, and data centers. AWS Regions are separate geographic areas around the world. Each Region contains multiple Availability Zones, which are designed to provide isolated infrastructure locations for improved availability and fault tolerance.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create and configure resources, monitor services, manage security settings, and view billing information through the console.

## Four Core Services

1. **Amazon EC2 (Elastic Compute Cloud)** – Provides scalable virtual servers for running applications and workloads.
2. **Amazon S3 (Simple Storage Service)** – Provides scalable object storage for files, backups, data, and application content.
3. **Amazon VPC (Virtual Private Cloud)** – Allows users to create isolated virtual networks for AWS resources.
4. **AWS IAM (Identity and Access Management)** – Controls access to AWS resources by managing users, roles, permissions, and policies.

## Three Advantages

1. **Scalability** – AWS resources can be increased or decreased based on workload requirements.
2. **Global Availability** – AWS provides infrastructure across many geographic regions, allowing organizations to deploy applications closer to their users.
3. **Wide Range of Services** – AWS provides many services that support computing, storage, databases, networking, security, analytics, and other cloud workloads.

## Typical Enterprise Use Cases

Enterprises use AWS for hosting websites and applications, storing and backing up large amounts of data, running databases, developing and testing software, disaster recovery, data analytics, and machine learning. AWS can also support organizations that need flexible infrastructure and global application deployment.
