# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview

This laboratory activity focused on exploring and comparing the three major cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The objective was to understand their services, infrastructure, management tools, advantages, and common enterprise use cases.

## Objectives

* Research AWS, Microsoft Azure, and Google Cloud.
* Identify important services offered by each cloud provider.
* Compare equivalent cloud services across the three platforms.
* Recommend suitable cloud platforms for different client requirements.
* Create a decision matrix for evaluating cloud platforms.
* Practice Linux commands using a cloud-based terminal environment.
* Document the completed activities and evidence using GitHub.

## Activities Performed

### 1. AWS Research

Researched AWS infrastructure, management console, core services, advantages, and enterprise use cases.

Core services studied:

* Amazon EC2
* Amazon S3
* Amazon VPC
* AWS IAM

### 2. Microsoft Azure Research

Researched Azure infrastructure, Azure Portal, core services, advantages, and enterprise use cases.

Core services studied:

* Azure Virtual Machines
* Azure Blob Storage
* Azure Virtual Network
* Microsoft Entra ID

### 3. Google Cloud Research

Researched Google Cloud infrastructure, Google Cloud Console, core services, advantages, and enterprise use cases.

Core services studied:

* Compute Engine
* Cloud Storage
* Google Cloud VPC
* Google Cloud IAM

### 4. Cloud Platform Comparison

Compared AWS, Azure, and Google Cloud based on:

* Compute
* Storage
* Networking
* Identity and access management
* Management consoles
* Global infrastructure
* Enterprise capabilities

### 5. Client Recommendations

Recommended appropriate cloud platforms for four different client scenarios based on their requirements and workloads.

### 6. Equivalent Cloud Services

Mapped equivalent services between AWS, Azure, and Google Cloud, including compute, storage, networking, databases, serverless computing, Kubernetes, IAM, monitoring, and other services.

### 7. Decision Matrix

Created a scoring matrix to compare the three platforms across important factors such as service breadth, scalability, enterprise integration, analytics and AI, global infrastructure, security, and management.

### 8. Linux Command-Line Practice

Used KillerCoda to practice Linux commands including:

```text
pwd
whoami
ls
mkdir
cd
touch
ls -la
echo
cat
rm -rf
```
