
# Multi-Cloud Explorer Reflection

This laboratory activity helped me understand the differences and similarities between the three major cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Before completing this activity, I mainly viewed cloud computing as a way to access computing resources through the internet. Through the research and comparison activities, I learned that cloud platforms provide a much broader collection of services for computing, storage, networking, security, databases, analytics, and application development.

One important lesson I learned is that AWS, Azure, and GCP provide many equivalent services, but they are not exactly the same. For example, Amazon EC2, Azure Virtual Machines, and Google Compute Engine all provide virtual-machine computing, while Amazon S3, Azure Blob Storage, and Google Cloud Storage provide object storage. Understanding these equivalents makes it easier to compare cloud platforms and choose appropriate services for a specific workload.

I also learned that choosing a cloud provider depends on the requirements of the organization. AWS is a strong general-purpose platform with a broad service portfolio. Azure is especially useful for organizations that already depend on Microsoft technologies. Google Cloud is particularly strong for data analytics, data processing, artificial intelligence, and machine learning workloads.

The KillerCoda activity also improved my confidence with Linux commands. Commands such as `pwd`, `ls`, `mkdir`, `cd`, `touch`, `cat`, and `rm` helped me practice basic command-line operations that are useful when working with cloud environments.

Overall, this laboratory improved my understanding of multi-cloud computing and showed me that cloud engineers need to evaluate platforms based on technical requirements rather than simply choosing one provider. The activity also strengthened my research, documentation, GitHub, and Linux command-line skills.
