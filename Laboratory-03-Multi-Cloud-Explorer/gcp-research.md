
# GCP Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a cloud computing platform provided by Google. It offers services for computing, storage, networking, databases, analytics, artificial intelligence, machine learning, and application development. Organizations can use Google Cloud to build and operate applications using Google's global cloud infrastructure.

## Global Infrastructure

Google Cloud operates a global infrastructure made up of regions and zones. A region is a geographic location containing multiple zones. Zones provide separate deployment locations within a region, helping organizations design applications with improved availability and resilience.

## Cloud Management Console

The **Google Cloud Console** is a web-based interface used to manage Google Cloud resources and services. Users can create and configure resources, monitor applications, manage permissions, view usage, and control cloud projects through the console.

## Four Core Services

1. **Compute Engine** – Provides configurable virtual machines for running applications and workloads.
2. **Cloud Storage** – Provides scalable object storage for data, files, backups, and application content.
3. **Virtual Private Cloud (VPC)** – Provides networking capabilities for connecting and securing cloud resources.
4. **Cloud Identity and Access Management (IAM)** – Controls access to Google Cloud resources through identities, roles, and permissions.

## Three Advantages

1. **Strong Data and Analytics Capabilities** – Google Cloud provides powerful services for processing, analyzing, and managing large datasets.
2. **Artificial Intelligence and Machine Learning** – Google provides a broad range of AI and machine learning technologies that can be integrated into cloud applications.
3. **Global Infrastructure** – Google Cloud provides a global network that supports applications and services across many geographic locations.

## Typical Enterprise Use Cases

Enterprises use Google Cloud for application hosting, data analytics, machine learning, artificial intelligence, storage, databases, software development, and large-scale data processing. Organizations can also use Google Cloud to modernize applications and build data-driven services.
