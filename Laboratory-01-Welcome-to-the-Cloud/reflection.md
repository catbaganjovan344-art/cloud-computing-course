# Reflection

This laboratory activity gave me hands-on experience using a cloud-based Linux environment through KillerCoda. I learned how to create and manage a Linux user account, navigate the Linux file system, and gather basic system information such as the operating system, kernel version, CPU, memory, and disk space.

I also learned how to create and organize directories and Markdown files using Linux commands. Creating the GitHub repository helped me understand how to organize laboratory outputs and maintain a structured cloud computing portfolio.

One of the challenges I encountered was working with the terminal and understanding how the current user affects the home directory. I also experienced an issue when pasting commands into the KillerCoda terminal, which helped me become more careful when entering Linux commands.

Overall, this activity improved my confidence in using Linux through a cloud-based environment and strengthened my skills in file organization, technical documentation, and GitHub-based portfolio management.
